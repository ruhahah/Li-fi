# Li-Fi Оптическая связь на Arduino Uno (Visible Light Communication)

## 📌 Описание проекта
Проект реализует **полнодуплексную беспроводную оптическую систему связи (Full-Duplex Li-Fi / VLC)** с протоколом гарантированной доставки данных **ARQ (ACK / NAK / Auto-Retransmit)**, аппаратным контролем **CRC-8**, звуковой телеметрией (Buzzer) и поддержкой русского языка (UTF-8).

## 🔌 Схема подключения трансивера

| Модуль | Компонент | Подключение к Arduino Uno |
| :--- | :--- | :--- |
| **TX (Передатчик)** | Светодиод (LED) | `Pin 13` $\to$ Резистор 150–220 Ом $\to$ Анод LED $\to$ `GND` |
| **RX (Приемник)** | Фотодиод BPW24 | **Катод** $\to$ `5V`<br>**Анод** $\to$ `Pin A0`<br>**Резистор** $\to$ `A0` на `GND` (5–10 кОм) |
| **Звук (Опционально)** | Пьезодинамик (Buzzer) | Плюс $\to$ `Pin 8`, Минус $\to$ `GND` |
| **Интерфейс с ПК** | Hardware Serial UART | Скорость **115200 baud** |

## ⚙️ Возможности протокола ARQ и Full-Duplex

1. **Гарантированная доставка (ARQ - Automatic Repeat reQuest)**:
   * При успешном приеме пакета и совпадении CRC-8 получатель автоматически отправляет оптический ответ **`[ACK]`**.
   * Отправитель видит статус: `>>> [СТАТУС ДОСТАВКИ]: ПАКЕТ ДОСТАВЛЕН ПОЛУЧАТЕЛЮ! ✔`.
   * При сбое или перекрытии луча отправитель **автоматически повторяет отправку (до 3 попыток)**.
2. **Звуковые эффекты (Buzzer на Pin 8)**:
   * Приветственный сигнал при старте.
   * Короткий щелчок при отправке.
   * Двойной приятный аккорд при получении оптического подтверждения ACK.
   * Звуковой сигнал ошибки при сбое CRC-8.
3. **Одновременный прием и передача (Full-Duplex)**:
   * Неблокирующие автоматы состояний (Zero Delay).
4. **Телеметрия оптического канала**:
   * Отношение Сигнал/Шум (SNR в дБ), оптический контраст $\Delta V$, скорость (байт/с, бит/с).
