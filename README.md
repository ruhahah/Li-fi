# Li-Fi Оптическая связь на Arduino Uno (Visible Light Communication)

## 📌 Описание проекта
Проект реализует **полнодуплексную беспроводную оптическую связь (Full-Duplex Li-Fi / VLC)** по лучу видимого света с модуляцией **OOK (On-Off Keying)**, неблокирующим программным асинхронным протоколом **UART (8-N-1)**, аппаратным контролем целостности **CRC-8** и одновременной двусторонней передачей между платами Arduino Uno.

## 🔌 Аппаратная схема подключения (для каждой платы)

### 1. Передающая часть (TX)
* `Pin 13` $\to$ Анод светодиода (через токоограничивающий резистор 150–220 Ом) $\to$ `GND`.

### 2. Приемная часть (RX)
* Фотодиод **BPW24**:
  * **Катод** $\to$ `5V` (обратное смещение).
  * **Анод** $\to$ `Pin A0`.
  * **Резистор** `5–10 кОм` $\to$ между `Pin A0` и `GND`.

### 3. Связь с ПК
* Скорость Serial Monitor: **115200 baud**.

## ⚙️ Параметры протокола

| Параметр | Значение | Описание |
| :--- | :--- | :--- |
| **Режим связи** | **Full-Duplex** | Одновременный независимый TX и RX (Zero CPU Delay) |
| **Скорость (Baud Rate)** | **30 бод** | 30 бит/с (длительность 1 бита $T = 33\,333\text{ мкс}$) |
| **Модуляция** | **OOK** | On-Off Keying (Свет = 1, Темнота = 0) |
| **Формат кадра** | **8-N-1** | 1 Start (HIGH), 8 Data (LSB first), 1 Stop (LOW), 1 Guard (LOW) |
| **Синхронизация** | **`micros()`** | Неблокирующий диспетчер состояний (без `delay()` и без `while()`) |
| **Кодировка** | **UTF-8** | Полная поддержка русского (Кириллица) и английского языков |
| **Контроль ошибок** | **CRC-8** | Полином $x^8 + x^2 + x + 1$ (`0x07`) |
| **Оверсэмплинг** | **3X Voting** | 3 замера в центре каждого бита ($-2000$, $0$, $+2000$ мкс) |
| **Порог** | **Динамический** | $\text{Threshold} = (\text{Фон} + \text{Пик старт-бита}) / 2$ |

## 🚀 Как пользоваться Full-Duplex трансивером ([lifi_trx.ino](file:///c:/Users/ashim/OneDrive/Desktop/Што-то/Li-fi/lifi_trx/lifi_trx.ino))
1. Загрузите скетч `lifi_trx.ino` на **обе** платы Arduino Uno.
2. Направьте светодиод первой платы на фотодиод второй, и светодиод второй платы на фотодиод первой.
3. Откройте два окна Serial Monitor на скорости **115200 baud**.
4. Вводите сообщения **одновременно в обоих терминалах** и нажимайте Enter в одну и ту же секунду:
   * Обе платы начнут параллельно светить своими светодиодами и одновременно считывать входящие фототоки с фотодиодов.
   * Ни одно сообщение не потеряется и не исказится, а в конце каждого пакета выведется подтверждение CRC-8 и метрики оптического канала (SNR, контраст, скорость).
