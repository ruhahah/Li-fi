# Li-Fi Односторонняя связь на Arduino Uno (Visible Light Communication)

## 📌 Описание проекта
Проект реализует беспроводную одностороннюю передачу текстовых данных по оптическому каналу (видимый свет / Li-Fi) с модуляцией **OOK (On-Off Keying)** и программным асинхронным протоколом **UART (8-N-1)** между двумя независимыми платами Arduino Uno.

---

## 🔌 Схема подключения

### 1. Передатчик (TX)
* **Arduino Uno** -> **Светодиодный модуль KY-009 / LED**
  * `GND` -> `GND` модуля LED
  * `Pin 13` -> Сигнальный пин (R/G/B или общий анод/сигнал модуля через токоограничивающий резистор 220–330 Ом)

### 2. Приемник (RX)
* **Arduino Uno** -> **Фотодиод PHYWE BPW24**
* Схема включения: **Делитель напряжения (Pull-Down)**
  * Катод фотодиода -> `5V` (обратное смещение / фотопроводимость)
  * Анод фотодиода -> `Pin A0` платы Arduino
  * Резистор `10 кОм` -> между `Pin A0` и `GND`

---

## ⚙️ Параметры протокола
* **Скорость:** 20 бод (бит/с) $\rightarrow$ длительность бита $T = 50\text{ мс}$.
* **Кадр:**
  * **Линия в покое (Idle):** `LOW` (светодиод выключен).
  * **Стартовый бит:** `HIGH` ($1 \times T$) — световой импульс пробуждения.
  * **8 бит данных:** LSB first ($8 \times T$).
  * **Стоповый бит:** `LOW` ($1 \times T$) — пауза и сброс линии в темноту.

---

## 🎯 Алгоритм синхронизации времени
Асинхронная оптическая передача работает без отдельной линии тактирования (Clock line):
1. **Захват фронта (Edge Detection):** Приемник ожидает перехода аналогового сигнала выше порога $Threshold$.
2. **Фазовый сдвиг $1.5 \times T$:** 
   * Сначала выжидается $0.5 \times T$ для валидации стартового бита в его центре (фильтрация кратковременных оптических шумов).
   * Затем выжидается $1.0 \times T$, в результате чего приемник попадает **ровно в геометрический центр 1-го бита данных**.
3. **Сэмплирование в центрах битов:** Каждый последующий бит опрашивается с фиксированным шагом $1.0 \times T$. Опрос строго посередине битового интервала нивелирует погрешности кварцевых резонаторов и задержки нарастания/спада фототока.
4. **Проверка стоп-бита:** На интервале стоп-бита проверяется отсутствие света (`LOW`).
