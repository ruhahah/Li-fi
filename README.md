# Li-Fi Оптическая связь на Arduino Uno (Visible Light Communication)

## 📌 Описание проекта
Проект реализует **высокоскоростную полнодуплексную систему оптической связи (Full-Duplex Li-Fi / VLC)** с поддержкой:
* Протокола гарантированной доставки данных **ARQ (ACK / NAK / Auto-Retransmit)**,
* Утилиты **Оптического Ping** с расчетом круговой задержки (RTT в мс),
* Алгоритма **аппаратного сжатия UTF-8 текста (x2 ускорение кириллицы)**,
* Аппаратного контроля целостности **CRC-8** и телеметрии оптического канала (**SNR в дБ**).

## 🔌 Схема подключения трансивера

| Модуль | Компонент | Подключение к Arduino Uno |
| :--- | :--- | :--- |
| **TX (Передатчик)** | Светодиод (LED) | `Pin 13` $\to$ Резистор 150–220 Ом $\to$ Анод LED $\to$ `GND` |
| **RX (Приемник)** | Фотодиод BPW24 | **Катод** $\to$ `5V`<br>**Анод** $\to$ `Pin A0`<br>**Резистор** $\to$ `A0` на `GND` (5–10 кОм) |
| **Интерфейс с ПК** | Hardware Serial UART | Скорость **115200 baud** |

## 🚀 Команды управления трансивером ([lifi_trx.ino](file:///c:/Users/ashim/OneDrive/Desktop/Што-то/Li-fi/lifi_trx/lifi_trx.ino))

1. **Отправка текста:** Введите любую фразу на русском или английском в Serial Monitor и нажмите Enter.
   * Текст автоматически сжимается в 2 раза, отправляется по лучу со скоростью **45 бод**, проверяется по **CRC-8**, а собеседник автоматически возвращает подтверждение **`[ACK]`**.
2. **Оптический Ping:** Введите команду **`ping`** и нажмите Enter.
   * Плата отправит оптический эхо-запрос и рассчитает точное время прохождения сигнала туда-обратно (**RTT в миллисекундах**).
3. **Замер АЦП:** Введите **`r`** для просмотра текущего уровня освещенности фотодиода.
4. **Калибровка темноты:** Введите **`c`** для автокалибровки базового шума.
