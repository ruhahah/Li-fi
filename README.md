# Li-Fi Оптическая связь на Arduino Uno (Visible Light Communication)

## 📌 Описание проекта
Проект реализует беспроводную оптическую связь по лучу видимого света (**Li-Fi / VLC**) с модуляцией **OOK (On-Off Keying)**, программным асинхронным протоколом **UART (8-N-1)**, аппаратным контролем целостности **CRC-8** и поддержкой полудуплексного режима трансивера (**Half-Duplex Transceiver / Рация**) между платами Arduino Uno.

## 🔌 Аппаратная схема подключения (для каждой платы в режиме трансивера)

### 1. Передающая часть (TX)
* `Pin 13` $\to$ Анод светодиода (через токоограничивающий резистор 150–220 Ом) $\to$ `GND`.

### 2. Приемная часть (RX)
* Фотодиод **BPW24**:
  * **Катод** $\to$ `5V` (обратное смещение).
  * **Анод** $\to$ `Pin A0`.
  * **Резистор** `5–10 кОм` $\to$ между `Pin A0` и `GND`.

### 3. Связь с ПК
* Скорость Serial Monitor: **115200 baud**.

## ⚙️ Параметры протокола

| Параметр | Значение | Описание |
| :--- | :--- | :--- |
| **Скорость (Baud Rate)** | **30 бод** | 30 бит/с (длительность 1 бита $T = 33\,333\text{ мкс}$) |
| **Модуляция** | **OOK** | On-Off Keying (Свет = 1, Темнота = 0) |
| **Формат кадра** | **8-N-1** | 1 Start (HIGH), 8 Data (LSB first), 1 Stop (LOW), 1 Guard (LOW) |
| **Синхронизация** | **`micros()`** | Абсолютная микросекундная привязка (Zero Cumulative Drift) |
| **Кодировка** | **UTF-8** | Полная прозрачная поддержка русского и английского языков |
| **Контроль ошибок** | **CRC-8** | Полином $x^8 + x^2 + x + 1$ (`0x07`) |
| **Оверсэмплинг** | **3X Voting** | 3 замера в центре бита ($-2000$, $0$, $+2000$ мкс) |
| **Порог** | **Адаптивный** | $\text{Threshold} = (\text{Фон} + \text{Пик старт-бита}) / 2$ |

## 🚀 Как пользоваться трансивером ([lifi_trx.ino](file:///c:/Users/ashim/OneDrive/Desktop/Што-то/Li-fi/lifi_trx/lifi_trx.ino))
1. Загрузите скетч `lifi_trx.ino` на **обе** платы Arduino Uno.
2. Направьте светодиод первой платы на фотодиод второй, и наоборот.
3. Откройте два окна Serial Monitor на скорости **115200 baud**.
4. Введите фразу на русском или английском в строку ввода любой платы и нажмите Enter — устройство перейдет в режим TX, передаст сообщение с CRC-8, а вторая плата примет пакет, проверит контрольную сумму и выведет телеметрию качества луча (SNR, оптический контраст, скорость).
