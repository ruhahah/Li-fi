# Li-Fi / Laser Оптическая связь на Arduino Uno (Laser VLC)

## 📌 Описание проекта
Проект реализует **высокоскоростную полнодуплексную систему лазерной оптической связи (Full-Duplex Laser Li-Fi / VLC)** с поддержкой:
* Передачи данных по коллимированному лазерному лучу (высокая дальность и четкость сигнала),
* **Интерактивного режима юстировки/прицеливания (`l` или `laser`)** с выводом шкалы АЦП в реальном времени,
* Протокола гарантированной доставки данных **ARQ (ACK / NAK / Auto-Retransmit)**,
* Утилиты **Оптического Ping** с расчетом круговой задержки (RTT в мс),
* Алгоритма **аппаратного сжатия UTF-8 текста (x2 ускорение кириллицы)**,
* Аппаратного контроля целостности **CRC-8** и телеметрии оптического канала (**SNR в дБ**).

## 🔌 Схема подключения трансивера

| Модуль | Компонент | Подключение к Arduino Uno |
| :--- | :--- | :--- |
| **TX (Передатчик)** | Лазерный модуль KY-008 (650 нм, 5 мВт) | **Signal (`S`)** $\to$ `Pin 13`<br>**GND (`-`)** $\to$ `GND`<br>*(При использовании голого лазерного диода без платы модуля — подключать через резистор 68–100 Ом)* |
| **RX (Приемник)** | Фотодиод BPW24 (или аналог) | **Катод** $\to$ `5V`<br>**Анод** $\to$ `Pin A0`<br>**Резистор нагрузки** $\to$ `A0` на `GND` (5–10 кОм) |
| **Интерфейс с ПК** | Hardware Serial UART | Скорость **115200 baud** |

> [!CAUTION]
> **Техника безопасности:** Никогда не направляйте луч лазера в глаза человеку или животным и избегайте зеркальных отражений!

## 🚀 Команды управления трансивером ([lifi_trx.ino](file:///c:/Users/ashim/OneDrive/Desktop/Што-то/Li-fi/lifi_trx/lifi_trx.ino))

1. **Юстировка лазера (Прицеливание):** Введите **`l`** или **`laser`** и нажмите Enter.
   * Лазер включится непрерывно, а в терминале появится живая шкала мощности сигнала:
     `[ЮСТИРОВКА] АЦП: 850 [================    ] >> ЛУЧ ПОЙМАН <<`
   * Направьте пятно лазера точно на линзу фотодиода для максимального значения АЦП.
   * Для выхода из режима юстировки повторно введите **`l`** или **`laser`**.
2. **Отправка текста:** Введите любую фразу на русском или английском в Serial Monitor и нажмите Enter.
   * Текст автоматически сжимается в 2 раза, передается лазерными импульсами со скоростью **45 бод**, проверяется по **CRC-8**, а собеседник автоматически возвращает подтверждение **`[ACK]`**.
3. **Оптический Ping:** Введите команду **`ping`** и нажмите Enter.
   * Плата отправит оптический эхо-запрос и рассчитает точное время прохождения сигнала туда-обратно (**RTT в миллисекундах**).
4. **Замер АЦП:** Введите **`r`** для быстрого просмотра текущего уровня освещенности фотодиода.
5. **Калибровка темноты:** Введите **`c`** для калибровки базового шума окружающей среды.
